# Шпаргалка по Git для начинающих

Этот репозиторий поможет тебе быстро вспомнить основные команды Git и избежать популярных ошибок.

## 1. Настройка (делается один раз)
Чтобы Git знал, кто автор правок, используй эти команды:
* `git config --global user.name "Alex717"` — задать имя.
* `git config --global user.email "alexandra717.as@gmail.com"` — задать почту.

## 2. Начало работы
* `pwd` — узнать, в какой ты сейчас папке.
* `cd ~` — быстро перейти в домашнюю директорию.
* `ls` — посмотреть список файлов в папке.
* `git init` — превратить обычную папку в репозиторий Git.

## 3. Сохранение изменений
* `git status` — проверить, что изменилось.
* `git add .` — подготовить **все** изменения к сохранению.
* `git commit -m "Твое сообщение"` — зафиксировать изменения (сделать «слепок»).
* `git log --oneline` — посмотреть историю всех коммитов в кратком виде.

## 4. Важные советы (грабли, на которые мы наступали)
1. **Знак `$`**: Если видишь в инструкции `$ git status`, копируй только `git status`. Знак доллара — это просто символ начала строки в терминале.
2. **Восклицательный знак**: Не используй `!` в тексте коммита внутри двойных кавычек (например, `"Ура!"`), иначе Bash выдаст ошибку. Используй одинарные кавычки: `'Ура!'`.
3. **Клавиша Tab**: Начинай писать имя файла и жми **Tab** — Git Bash сам допишет название за тебя.
